# Getting help

Thank you for using FileStudio! Here is where to get help.

## Before you ask

- Read the **[README](README.md)**, especially [Getting started](README.md#getting-started) and
  [Known limitations](README.md#known-limitations). Some things are not supported yet, for example editing
  (planned for 0.2.0) or charts in `.xlsx` files.
- Make sure you use the **latest version** of FileStudio and VS Code 1.90 or later.
- **Search the [existing issues](https://github.com/yokeeswaran-dev/vscode-filestudio/issues?q=is%3Aissue)**
  (open and closed). Someone may already have reported the same thing.

## Where to ask

| You want to... | Go to |
| --- | --- |
| Report a bug | [New bug report](https://github.com/yokeeswaran-dev/vscode-filestudio/issues/new?template=bug_report.md) |
| Suggest a feature or an improvement | [New feature request](https://github.com/yokeeswaran-dev/vscode-filestudio/issues/new?template=feature_request.md) |
| Ask a question or share an idea | [GitHub Discussions](https://github.com/yokeeswaran-dev/vscode-filestudio/discussions) (if enabled for the repository), otherwise a [new issue](https://github.com/yokeeswaran-dev/vscode-filestudio/issues/new/choose) |
| Report a security problem | **Not in public.** See [SECURITY.md](SECURITY.md) |

## What to include

A good report helps us to help you faster. Please include:

- **FileStudio version** (Extensions view → FileStudio), **VS Code version** (Help → About) and your **operating system**.
- The **file type** (for example `.xlsx` or `.pdf`) and its **size**.
- **Steps to reproduce**: what you did, what you expected, and what happened instead.
- A **sample file** that shows the problem, if you can share one. Please remove private or personal data first.
- **Screenshots**, if they help to show the problem.
- **Logs:** open **View → Output** and choose **FileStudio** in the list. For a viewer that stays blank or looks
  wrong, also run **Developer: Open Webview Developer Tools** and copy the errors from the **Console** tab.

## Response times

FileStudio is a small open-source project. We answer issues and questions as soon as we can, but we cannot promise a
response time. Thank you for your patience.
